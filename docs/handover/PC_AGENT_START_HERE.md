## 避免重工與無限延遲
- 每個任務只做「讀相關證據 → 實作 → 相關測試 → 一次整合審閱 → PR／下一項」。有新變更、失敗或明確風險才追加檢查。
- 一般可逆修復不反覆請示；低影響文件修改不新增測試工程。不要把所有階段串成全域阻擋。
- 同一阻礙連續兩次嘗試無新證據時記下原因、所需決策及可繼續項目，停止盲目重試。
- 不承諾無限背景運行。受 session／額度限制時記錄 branch、SHA、已完成、下一條命令與 blocker，下一次直接續作。
- 每批完成回報實際可用行為與證據；全面矩陣只更新有變更的列。NO MOCK AS DONE；不宣稱未測的 production 成功。
